PUZZLE ATLAS — COMPLETE PORTABLE PROJECT

1. Preserve this folder structure. The website is entirely inside dist/.
2. For GitHub Pages, use the included .github/workflows/static.yml and choose
   GitHub Actions as the Pages publishing source. It publishes ./dist.
3. For a local copy, open a terminal here and run:
      python3 -m http.server 8000 --directory dist
   Then visit http://localhost:8000. No external server or internet is needed
   for local play. Do not double-click an HTML file; file:// blocks the solver.
4. Before committing/deploying, run:
      node scripts/verify-release.cjs
   This checks every website file and all solver fingerprints. No npm install.
5. Replace your old dist folder as a unit. Include all new files in the commit
   (git add .), especially games/color-solver-caches/. Do not merge only pieces
   of different releases. Keep your .git folder; this ZIP contains no history.
6. After replacing a previously deployed version, hard-refresh once.

The app uses only files included in dist. It has no API keys, passwords,
tracking scripts, remote fonts, CDN libraries, or development-host connection.
Computation runs locally in the browser; JSON models are read from the same
server that serves the page. The guide's optional scholarly links go outside
the site only when you open them.

The complete project also includes solver-backend, scripts, tests, research,
guide-research, license, and documentation.
